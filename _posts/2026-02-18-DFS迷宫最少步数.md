>在迷宫问题中，除了判断是否能够走通之外，我们经常需要找到从起点到终点的**最短路径**。本文将介绍如何使用深度优先搜索（DFS）和广度优先搜索（BFS）来解决迷宫最少步数问题。

## 问题描述

给定一个`n×m`的迷宫矩阵，其中`0`表示可以通过的路，`1`表示墙壁。给定起点坐标`(sx, sy)`和终点坐标`(ex, ey)`，求从起点到终点的**最少步数**。如果无法到达，则输出`-1`。

## 算法对比

### DFS vs BFS

- **DFS（深度优先搜索）**：一条路走到底，适合判断连通性，但不保证找到最短路径。需要遍历所有可能路径才能确定最短路径。
- **BFS（广度优先搜索）**：层层扩散，**第一次到达终点时就是最短路径**，是求最短路径的首选算法。

对于求**最少步数**问题，**BFS是最优选择**！

## BFS解法（推荐）

### 核心思路

1. 使用队列存储待访问的节点和对应的步数
2. 从起点开始，将其入队（步数为0）
3. 每次从队列取出一个节点，向四个方向扩展
4. 第一次到达终点时，就得到了最短路径

### 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
int sx, sy, ex, ey;
int maze[110][110];
bool visited[110][110];
int dx[4] = {-1, 1, 0, 0};  // 上下左右
int dy[4] = {0, 0, -1, 1};

struct Node {
    int x, y, step;
};

int bfs() {
    queue<Node> q;
    q.push({sx, sy, 0});
    visited[sx][sy] = true;
    
    while (!q.empty()) {
        Node cur = q.front();
        q.pop();
        
        // 到达终点
        if (cur.x == ex && cur.y == ey) {
            return cur.step;
        }
        
        // 向四个方向扩展
        for (int i = 0; i < 4; i++) {
            int nx = cur.x + dx[i];
            int ny = cur.y + dy[i];
            
            // 判断是否合法
            if (nx >= 1 && nx <= n && ny >= 1 && ny <= m 
                && maze[nx][ny] == 0 && !visited[nx][ny]) {
                visited[nx][ny] = true;
                q.push({nx, ny, cur.step + 1});
            }
        }
    }
    
    return -1;  // 无法到达
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> maze[i][j];
        }
    }
    cin >> sx >> sy >> ex >> ey;
    
    if (maze[sx][sy] == 1 || maze[ex][ey] == 1) {
        cout << -1 << endl;
        return 0;
    }
    
    int result = bfs();
    cout << result << endl;
    
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：O(n×m)，每个节点最多访问一次
- **空间复杂度**：O(n×m)，队列和visited数组的空间

## DFS优化解法

如果一定要用DFS求最短路径，需要遍历所有可能的路径，并记录最小步数：

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
int sx, sy, ex, ey;
int maze[110][110];
bool visited[110][110];
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};
int minStep = INT_MAX;

void dfs(int x, int y, int step) {
    // 剪枝：如果当前步数已经超过已知最小步数，直接返回
    if (step >= minStep) return;
    
    // 到达终点
    if (x == ex && y == ey) {
        minStep = min(minStep, step);
        return;
    }
    
    // 向四个方向探索
    for (int i = 0; i < 4; i++) {
        int nx = x + dx[i];
        int ny = y + dy[i];
        
        if (nx >= 1 && nx <= n && ny >= 1 && ny <= m 
            && maze[nx][ny] == 0 && !visited[nx][ny]) {
            visited[nx][ny] = true;
            dfs(nx, ny, step + 1);
            visited[nx][ny] = false;  // 回溯
        }
    }
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> maze[i][j];
        }
    }
    cin >> sx >> sy >> ex >> ey;
    
    if (maze[sx][sy] == 1 || maze[ex][ey] == 1) {
        cout << -1 << endl;
        return 0;
    }
    
    visited[sx][sy] = true;
    dfs(sx, sy, 0);
    
    if (minStep == INT_MAX) {
        cout << -1 << endl;
    } else {
        cout << minStep << endl;
    }
    
    return 0;
}
```

### DFS注意事项

1. **回溯**：访问完一个节点后要恢复visited状态
2. **剪枝**：当前步数超过已知最小值时直接返回
3. **效率低**：需要遍历所有路径，时间复杂度可能达到O(4^(n×m))

## 总结

- 求**最短路径/最少步数**：优先使用**BFS**
- 求**是否连通**：DFS和BFS都可以
- BFS保证第一次到达终点就是最短路径
- DFS需要遍历所有路径才能确定最短路径，效率较低
