本题用贪心+单调栈优化,复杂度O(n).
# 背景
题目描述给定一个 $n$ 位的高精度正整数，从中删去 $s$ 个数字，使得剩余的数字按原左右次序组成的新数最小。
# 核心思路
贪心策略我们要让剩下的数最小，关键在于：让更小的数字占据更高的数位。
- 局部最优解：从左往右看，一旦发现某位数字比它右边的数字大（出现“山峰”），就立刻删掉它。
- 全局最优解：通过多次局部删除，最终得到的数字序列一定是递增的（或名额用光），从而达到整体最小。
# 算法实现：单调栈（Monotonic Stack）
为了高效处理删除操作，我们使用 std::string 来模拟一个栈：逐个入栈：遍历原字符串 num 中的每个字符 c。
- 连环踢人（While循环）：如果当前字符 c 比栈顶数字小，且我们手里还有删除名额 s。
- 动作：弹出栈顶（pop_back），名额减一。原理：利用 while 确保只要名额够，就能把前面所有的“大山峰”全部推倒。
- 特殊情况处理：如果遍历结束名额 s 还没用完（说明剩下的序列是递增的，如 12345），则从末尾继续删除。
- 前导零处理：利用下标 pl 找到第一个非 0 的位置，但需保留最后一位（防止结果全为 0 时输出为空）。
- 满分代码实现:
```
#include <iostream>
#include <string>
using namespace std;
int main()
{
    string num,res="";
    int s,pl=0;
    cin>>num>>s;
    for(char c : num){
        while(s>0&&!res.empty()&&res.back()>c){
            res.pop_back();
            s--;
        }
        res.push_back(c);
    }
    //------------------------
    while(s>0&&!res.empty()){
        res.pop_back();
        s--;
    }
    while(pl<res.size()-1&&res[pl]=='0'){
        pl++;
    }
    for(int i=pl;i<res.size();i++){
        cout<<res[i];
    }
    return 0;
}
```
- 复杂度分析时间复杂度：$O(n)$。虽然有嵌套循环，但每个数字最多入栈一次、出栈一次，性能极佳，足以应对 $10^6$ 级别的数据。空间复杂度：$O(n)$。需要一个额外的字符串 res 来存储结果。
